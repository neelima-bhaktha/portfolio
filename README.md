# Portfolio

A unique web portfolio built using pure HTML and Tailwind CSS. The design features a deep royal blue background framed by a vibrant yellow stitched border style. 

The standout feature of this portfolio is its physical interactivity. When a user chooses to print the page, the layout shifts into a foldable three dimensional cube net template. Recruiters can print it out, cut along the lines, and fold it into a tangible desk toy that displays all important professional information.

## Project Features

* **Stitched Aesthetic** A custom user interface matching deep blue with a dashed yellow border structure.
* **Tactile Experience** A print view that translates digital web content into a real world origami cube.
* **Six Face Architecture** The portfolio condenses core information into six distinct sections for each side of the cube.
* **Pure Performance** Built using native web technologies ensuring instant loading times with zero framework overhead.

## Core Portfolio Sections

1. **Introduction** A brief personal summary and professional title.
2. **Work Experience** Highlights of recent industry internships and roles.
3. **Projects** Detailed showcase of key technical engineering builds.
4. **Tech Stack** A clean visual grid of preferred languages and tools.
5. **Personal Elements** Curated entertainment links including Spotify Blend and Letterboxd.
6. **Professional Links** Actionable connection paths including GitHub and LinkedIn profiles.
